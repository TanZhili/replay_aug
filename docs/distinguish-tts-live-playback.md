# 如何区分 TTS、不同麦克风的真人语音，以及电子设备外放

本文讨论一个三类问题：一段语音到底是

1. **TTS 文件**（合成器直接输出，没有经过嘴，也没有经过房间里的扬声器）；
2. **真人语音**（声带发声，被不同档次的麦克风收录）；
3. **电子设备外放**（电视、手机、音箱、车机等把一段节目播出来，再被麦克风收录）。

材料来自本仓库 `README.md` 引用的 2020 年及以后的工作，并补了同一问题上直接相关的后续论文。年份以发表或挑战举办年为准。2019 年及更早的语料（ReMASC、ASVspoof 2019）只在被这些论文当作训练或对照时出现。

结论先写在前面：这三类不能用同一个检测器、同一套「像不像重放」的分数分开。深伪检测器学的是合成器痕迹；ASVspoof 物理访问（PA）检测器学的是**第二次**录音；麦克风档次改变的是采集链，三类都会经过它。能分开「嘴」和「喇叭」的，是声源辐射和播放设备自己的链路，而且必须让房间、噪声和麦克风在两类之间对齐。

```text
                    ┌─ 没有房间、没有喇叭 ─→ TTS 文件（逻辑访问 / 深伪）
一段音频 ──────────┤
                    └─ 有房间、有麦克风 ─┬─ 声源是嘴 ─→ 真人（麦克风档次在这里起作用）
                                        └─ 声源是喇叭 ─→ 电子设备外放
                                              └─ 若节目本身是 TTS，合成痕迹大多已被喇叭滤掉
```

---

## 1. 三类信号各自留下什么

把采集过程拆开，三类的差异才看得清。

| | TTS 文件 | 真人，经麦克风 | 电子设备外放，经麦克风 |
| --- | --- | --- | --- |
| 声源 | 声码器或神经解码器 | 声门 + 声道，嘴的指向性 | 扬声器单元，常是多只、有指向、有箱体 |
| 节目处理 | 合成器内部 | 没有 | 响度、压缩、限幅、配乐、播出编解码（AAC、Opus、AMR 等） |
| 房间 | 没有，或只是合成时加的人工混响 | 一次传播：直达声 + 反射 | 一次传播。经典「重放攻击」才是两次 |
| 设备失真 | 声码器的周期性、过度平滑 | 近讲时的喷气、齿音 | 小喇叭高通、谐振峰、功放限幅、振膜非线性 |
| 麦克风 | 没有 | 有，档次决定高频、底噪、AGC | 有。若和真人用同一只麦克风，这项不能当特征 |

本仓库要服务的全双工拒识，问的是后两列：同一个人机场景里，这句话是人说的，还是电视/手机放的。TTS 是造数据用的声源，不是要检出的类别。公开文献几乎都把问题收成两分类，而且两分类的定义和这张表对不齐。后面每一节都先标明论文实际在分哪两类。

## 2. 深伪检测器分的是「合成器」，过了喇叭就失效

这一支的正类是录音（通常是演播室或众包真人），负类是 TTS / 声音转换。代表系统是 wav2vec 2.0 特征加 AASIST、RawNet2、LFCC-LCNN。它们在干净文件上可以很强，一旦声音从扬声器里放出来再录回去，合成痕迹会被喇叭的频响和房间卷积抹掉。

### ReplayDF（Müller 等，Interspeech 2025）

把 M-AILABS 的真人录音和 MLAAD 的合成语音，用 109 组扬声器–麦克风在六种语言上播放再录，共 132.5 小时。TTS 为 Bark、VITS、XTTS v1.1、XTTS v2。

- 公开权重里最好的 W2V2-AASIST，在原始文件上 EER 10.6%，重录后升到 24.8%。
- 在 ODSS 上重训后，原始文件 EER 4.7%，重录后 18.2%。用该数据集的房间脉冲响应做增强，重录 EER 降到 11.0%，原始文件 EER 降到约 2.2%，缺口还在。
- 掉下去的全是合成样本：各 TTS 的检出准确率下降约 28–44 个百分点。真人重录后的准确率几乎不动（约 98%）。
- 往原始文件里加高斯、白、粉红噪声（15–40 dB SNR）几乎不造成同样的下降。抹掉线索的是喇叭和房间的卷积，不是「变吵了」。
- 录音质量越差，深伪越难抓：检出准确率与 MOS 的相关系数 0.423，与 PESQ 0.509。劣质播放比高保真播放更能把合成语音伪装成真人录音。

因此：一段音频如果已经是外放录音，深伪分数回答的是「合成痕迹还剩多少」，不是「这是不是喇叭」。高保真音箱留下的合成痕迹多一些，手机和廉价喇叭留下的少一些。

### EchoFake（Zhang、Huang、Ren，ICASSP 2026）

把问题明确做成四类：真人（B）、重放的真人（RB）、零样本 TTS（F）、重放的 TTS（RF）。81,890 条，13,005 人，11 个 TTS，126.4 小时。闭集用 MacBook / iPad 播放、手机录，两个房间、15 cm 和 50 cm；开集换成监听音箱、小米手机和有线耳机麦，另一个房间、30 cm。全部再压到 −23 LUFS 和 64 kbps MP3。

- 只用既有深伪数据训练的模型，遇到重放音频时平均准确率掉到 59.6%。
- 在 EchoFake 上训练后，开集四分类仍然拆不开重放：RawNet2 / AASIST / wav2vec2 对 RB 的 F1 只有 27.1 / 26.3 / 40.1，对纯 TTS（F）仍有 72.8 / 79.9 / 75.6。重放真人最像真人；重放合成是「合成痕迹 + 信道失真」的混合物。
- 二元检测（把 RB、F、RF 都当攻击）开集 EER：wav2vec2 11.86%，AASIST 14.88%，RawNet2 21.13%。闭集可以到 0.27–3.95%，换设备就崩。
- 训练时拿掉重放样本，在常规深伪集上 EER 变化不大，加上 EchoFake 开集后平均 EER 上升 1.5–6.2 个百分点。重放数据主要是在补「过喇叭」这一支，不是在提高干净 TTS 的检出。

EchoFake 还指出另一个和麦克风档次直接相关的失败：在演播室数据上训练的检测器，会把消费电子设备录的真人判成假。麦克风和房间的变化，会被当成合成痕迹。

### ASVspoof 2021 的逻辑访问与深伪轨（Yamagishi 等，2021；Liu 等，IEEE/ACM TASLP 2023）

逻辑访问（LA）是电话信道上的 TTS / 声音转换，没有声学传播。深伪轨（DF）是媒体压缩后的合成语音，不接说话人确认。官方基线在评测集上：LA 的 LFCC-LCNN EER 9.26%；DF 的 RawNet2 22.38%、LFCC-LCNN 23.48%。DF 赛程中进度集最好可以低于 1%，评测集全部高于 15%，最好 15.64%。神经声码器比传统声码器更难抓；压缩格式之间差异大，ogg 比 mp3 / m4a 更容易，双次转码并不必然更难。

Liu 等对隐藏子集的分析说明，LA 上很多系统在利用句首句尾的静音：TTS 往往没有真人录音那种长静音，去掉非语音段后代价明显变差。这和后面 PA 上的静音捷径是同一类问题。

**对三类问题的用法：** 深伪检测器只适合第一类对「同档麦克风、同信道的真人文件」。它不能判断外放，也不能在麦克风档次变化时保持「真人」这个标签。外放之后，应把它的分数当成「残留合成痕迹」，并预期劣质喇叭会把这个分数压下去。

## 3. 重放检测器分的是「第二遍录音」，不是「嘴对喇叭」

物理访问文献里的攻击是：攻击者先录下目标说话人，再拿到验证麦克风前播放。正类和负类往往都带混响和噪声。ASVspoof 2021 PA 把这一点做到了极端。

### ASVspoof 2021 PA

评测集是真实房间、真实设备。670 句 VCTK 作为种子。所谓 bona fide **不是人在说话**：种子由一只频响相当平坦的高品质扬声器播放，在 9 个房间、3 档 ASV 麦克风、6 个距离上录，共 162 个声学条件。攻击是在同样的房间里再录一次、再用另一台设备放一次。两边都有混响和设备噪声，并被截到 16 kHz，句首句尾超过 0.3 秒的静音被去掉。

官方基线只用 ASVspoof 2019 的**仿真** PA 训练，没有数据增强。评测 EER：

| 系统 | PA EER |
| --- | --- |
| CQCC-GMM | 38.07% |
| LFCC-GMM | 39.54% |
| LFCC-LCNN | 44.77% |
| RawNet2 | 48.60% |

最好的参赛系统（T07，DKU-CMRI）EER 24.25%，min t-DCF 0.6824。PA 的 t-DCF 离「完美检测器、不完美的说话人确认」那条下界仍很远。Liu 等按条件拆开前十名后，房间大小和成绩没有稳定关系；更难的是这些条件：

- 攻击者的麦克风更好（m1、m2 优于劣质的 m3）；
- 攻击者的扬声器更好（s3、s4）；
- 攻击者离说话人更近（最近的 c4 最难）；
- 说话人离 ASV 麦克风更远时，正类本身也更差，误拒上升。

也就是说，PA 检测器依赖的是**第二遍**多出来的那一层设备着色。第一遍如果已经是一只好喇叭，它和「再放一次的好喇叭」在频谱上很接近。这正是本仓库 `README` 写明的：这些检测器学的不是嘴对喇叭。电视播放演播室节目只经过一次喇叭、一次房间，幅度上应弱于真正的二次重放。

### 压缩残差与声码器残差（约 22–24% EER）

两条最好的公开结果用的是同一种想法：用一个会保住内容和说话人、丢掉信道的前端，把原信号减掉，剩下的当作重放信道。

- Wang 等（ASVspoof 2021 研讨班）：假设声码器能部分消掉重放信道，用原频谱和声码器频谱之差做特征，后面接一类异常检测，再加 pyroomacoustics 与变速增强。PA 评测 24.25% EER。他们不用判别式深度网络，因为 2019 仿真和 2021 真实房间差太大。
- Xie 等（arXiv 2023，*Audio compression-assisted feature extraction*）：WORLD 声码器重合成，再用 Opus（VoIP 模式，16 kHz 单声道）以远低于原始码率压缩后解码，Mel 频谱相减。Opus 16 kbps + AnoGAN 在 2021 PA 评测集上 22.71% EER；同设置的 VAE / 单类 SVM 为 23.40% / 22.75%。码率从 16 kbps 降到 8 kbps，EER 升到约 25%。作者认为这是当时该评测集上最低的 EER。

残差有效，是因为二次录音的信道噪声和扬声器着色不属于「声码器认为的语音」。它不能直接搬到「电视对真人」：电视节目在进喇叭之前就已经是 AAC / AC-3，真人没有这条节目链，但真人麦克风的底噪也会进残差。残差必须在**同一只麦克风**上比较，否则麦克风档次会主导差值。

### RIRplay（Sanchez-Valera 等，IEEE TIFS 2026）

针对「2019 仿真训、2021 真实测」的落差，用仿真把整条重放链做全，而不是只做数据增强。

生成要点：

- 种子仍是 VCTK，规模先与 ASVspoof 2019 PA 对齐，再有一份把种子句数加倍的扩展集。
- 房间来自 ACE Challenge 的实测混响：7 个房间 × 2 种摆位 × 8 通道，共 112 个环境，RT60 按倍频程给出，而不是一个标量 T60。用 Roomsimove 的镜像源法生成 RIR。
- 专门做最难的情形：攻击者和说话人在**同一间房**，但偷录和 ASV 呈现用不同的 RIR、不同的距离。噪声来自同一段环境声，偷录和重放之间加延迟，SNR 在 25–35 dB 均匀抽取。
- 扬声器沿用 2019 的广义多项式 Hammerstein 模型，40 只，分 perfect / high / low。麦克风频响仍不建模（假定平坦）。
- 补偿 RIR 直达声延迟和扬声器谐波的固定延迟（2048 样本），幅度归一化，并用 VAD 去掉首尾静音，避免模型学静音。
- 每条 spoof 在元数据里指向对应的 bona fide，形成立体声配对。

wav2vec 2.0 + Conformer，在扩展、延迟补偿、静音抑制的 RIRplay 上训练，ASVspoof 2021 PA 的 EER 从 2019 训练的 36.89% 降到 28.04%；AASIST 从 37.91% 降到 29.69%。ReMASC（含车内的真实多通道重放）上两者都在 33.9% 左右。消融里，环境从 112 个减到 27 个，2021 上的 EER 从约 30.7% 升到 33.4%；SNR 降到 15–25 dB 反而变差（32.9%）。25–35 dB 的轻度噪声最好。

RIRplay 自己的条件分析（最好的 Conformer）和 Liu 等一致：房间没有稳定趋势；说话人离麦克风远（D1 = 2.0 m）或 ASV 麦克风差（M3）时，正类更易被拒；攻击距离近、麦克风好时，攻击更易被接受。28% 的 EER 大约能排进 2021 PA 前五，而且是单系统，不是多系统融合。作者明确写了还没做的事：非矩形房间和家具、攻击者麦克风与 ASV 麦克风的频响、把立体声配对用进检测器。

RIRplay 改善的是「仿真的二次重放 → 真实的二次重放」。它仍然不是嘴对喇叭。

### 本仓库用这两个检测器做的同场景对照

`README` 用 ASVspoof 2021 官方 LFCC-LCNN（2019 仿真训练）和一份在 2021 PA 真实录音上微调的 wav2vec2，对同一场景里的真人版、外放版、以及「把真人版再放一次」的阳性对照打分。240 对上：

| | LFCC-LCNN | wav2vec2 |
| --- | --- | --- |
| 真二次重放比真人更像重放 | 88%，AUC 0.78 | 79%，AUC 0.70 |
| 外放比真人更像重放 | 72%，AUC 0.66 | 65%，AUC 0.61 |
| 外放−真人的中位分差，相对二次重放−真人 | +0.67 / +1.77 | +0.18 / +0.54 |

外放的分离大约是真二次重放的三分之一到五分之二，和「只经过一次喇叭」一致。车舱最低（约 56–60%），因为全频多单元、混响短、噪声大，而且 ASVspoof 训练数据里没有车舱。干净 TTS 会被 LCNN 判成极像重放（live 比 dry 更像重放的 AUC 为 0），会被 wav2vec2 判成「一带混响就像重放」（AUC 0.98）。两类放进同一场景后，这两种偏差会抵消。

这份对照说明：现成 PA 检测器对外放有一点敏感，但敏感的是二次录音伪影的弱化版。为了让它们打高分而把外放数据做成二次录音，会把训练带离真实的电视和手机。

## 4. 频谱功率能分开嘴和廉价喇叭，高保真喇叭会靠拢

### Void（Ahmed 等，USENIX Security 2020）

Void 是轻量活体检测：97 维特征、一棵分类树，比较真人说话和扬声器重放的累积功率谱。STFT 窗长 1024、跳步 256、FFT 4096，沿时间把每个频点的功率加起来。

它依赖三个观察：

1. 人声功率集中在大约 20 Hz–1 kHz，累积功率在 1 kHz 附近按指数下降。廉价喇叭为了响度和灵敏度牺牲保真，功率沿频率更均匀、更线性。
2. 高品质音箱会在很宽的频带上补功率，指数下降不再够用。此时要看 2 kHz 以下的精细起伏：人声峰又密又尖，音箱更平、尖峰更少。
3. 高频功率分布（他们用到 10 kHz 一带）提供第三组特征。ASVspoof 2017 上，CART 认为低频线性度和低频峰值结构最重要。

成绩：自采数据（120 人，15 个播放设备，12 个录音设备，255,173 条）EER 0.3%；ASVspoof 2017 评测集 EER 11.6%，优于当时的 CQCC-GMM（约 23%），差于 STFT-LCNN（7.4%）。和 MFCC-GMM 融合后 8.7%。对语音合成的检出率约 90.2%，对均衡器攻击约 86.3%。高品质监听音箱明显更难：Dynaudio BM5A 92.7%，Behringer Truth B2030A 95.1%，Genelec 6010A 掉到 81.1%。

Void 和本仓库的设备预设是同一物理事实的两端。人声在 1 kHz 以上自然衰减；手机、平板、笔记本的小喇叭还有几百赫兹的高通，电视和条形音箱低一些，车机和监听音箱可以接近全频。所以：

- 手机、平板、笔记本外放，用频带边缘和低频功率形状就比较好分；
- 电视、条形音箱居中；
- 车机、高品质音箱和「人在同一房间里说话」会靠拢，必须靠失真、多单元、节目链，而不是整段频谱的斜率。

Void 的真人是对着设备说的口令，距离近，低频峰和喷气都在。客厅里的人离麦克风一米以上时，这些近讲线索会弱，不能把 Void 的 0.3% 外推到远场。

## 5. 麦克风档次是第三轴，和声源正交

麦克风不产生「是不是 TTS」或「是不是喇叭」，它给所有经过它的声音加上同一层：

- 高频滚降和 MEMS 的谐振；
- 底噪，安静房间里尤其明显；
- AGC、高通、削波；
- 采样率。16 kHz 文件在 8 kHz 处截断，Void 用的 10 kHz 线索直接消失。

文献里能分开的规律：

- **攻击侧麦克风越好，二次重放越难检**（ASVspoof 2021 的 m1/m2 对 m3；RIRplay 的条件分析）。好麦克风少加失真，第二遍更干净。
- **验证侧麦克风越差，真人（或第一遍播放）越容易被拒**（M3、远距离 D1）。差麦克风自己的噪声和滚降会被检测器当成攻击。
- **深伪检测器会把「录得差」当成「假」**（EchoFake 对消费设备真人的误报；ReplayDF 对 In-the-Wild、ASVspoof 2019 一类训练集的警告：噪声模式在正负类之间不平衡时，模型把音质差等价于假）。
- **重放把合成痕迹洗掉的程度随录音质量下降而加重**（ReplayDF 的 MOS / PESQ 相关）。同一句 TTS，监听音箱加重录麦上仍可能被深伪模型抓住，手机喇叭加耳机麦上往往抓不住。

所以「不同级别的麦克风收录的真人」不能靠一个在演播室真人上训练的分类器来认。要把目标设备的麦克风放进训练，并且让外放类走**同一只**麦克风。否则模型用底噪和高频就能把类分开，换一只麦就失效。本仓库把 MEMS 频响、自噪声、高通、AGC、ADC 放在共享采集链里，就是为了去掉这条捷径。

麦克风档次可以单独做设备识别（录音设备指纹），那是另一题。它不能代替声源分类。

## 6. 哪些线索在三类之间真正有效

下面按「换房间、换麦克风、换说话内容之后还在不在」来排。只在某一套数据集里显著的，标成捷径。

### 6.1 能分开 TTS 文件和任何真实采集

| 线索 | 依据 | 失效条件 |
| --- | --- | --- |
| 声码器的过平滑、基频过于稳、缺少呼吸和喷气 | LA / DF 上神经声码器仍是主线索；传统声码器更容易 | 过喇叭再录（ReplayDF、EchoFake 的 RF） |
| 句首句尾静音模式 | Liu 等：去掉非语音后 LA 明显变差 | 双方都做 VAD 之后；RIRplay 因此主动去掉静音 |
| 完全没有房间 | 干文件对带混响文件 | 合成器自己加了混响，或评测前统一加 RIR |

干 TTS 不是「真人」。本仓库的实测里，干 TTS 会被重放检测器打到两个相反的极端。训练拒识时，真人列必须是进过房间和麦克风的声音。

### 6.2 能在同一房间、同一麦克风下分开嘴和喇叭

这些线索不依赖「第二遍录音」。

| 线索 | 物理来源 | 对哪些设备管用 | 论文里的对应 |
| --- | --- | --- | --- |
| 低频滚降 / 高频不足 | 小口径喇叭的高通和频响 | 手机、平板、笔记本强；电视中等；车机和监听弱 | Void 的累积功率；本仓库按设备设的高通 |
| 低频峰的疏密 | 嘴的谐波 vs 音箱的平滑 | 近讲、高采样率时更清楚 | Void 对高品质音箱的第二组特征 |
| 谐波失真、限幅 | 功放和振膜，音量越大越强 | 接近满幅的小喇叭；高保真在正常音量下很弱 | ASVspoof / RIRplay 的 Hammerstein 模型 |
| 节目链 | 播出编解码、响度、配乐、对白处理 | 电视、流媒体、电话；现场说话没有 | 压缩残差的思想可借用，但节目本身已压缩 |
| 多单元的空间展宽 | 低音和高音不在同一点 | 有麦克风阵列时 | 本仓库的已知局限：单通道只能部分体现 |
| 嘴的指向性 | 高频向前，侧向变暗 | 远场、有角度时 | 与喇叭指向性不同；RIRplay 未建模 |

房间的 RT60、噪声种类、麦克风频响，在同一场景里两类共享，不能用。RIRplay 和 Liu 等都观察到房间体积和检测成绩没有稳定关系：混响不是重放的定义特征。ReplayDF 进一步说明加性噪声也不是合成痕迹消失的原因。

### 6.3 只对「第二遍」有效、不能当成外放定义的线索

- 双倍混响：偷录房间再卷积播放房间。电视节目的演播室混响在进喇叭之前就有，和「攻击者在客厅里又录了一次」不是同一件事。
- 攻击者麦克风的着色再叠加播放设备。外放只有播放设备这一次。
- 在 ASVspoof 2017 里被利用过的开头噪声、爆音、坏文件。Void 的 11.6% 有一部分建立在这个语料上，换到干净数据会变。

### 6.4 静音、音质、带宽不匹配都是捷径

- 静音长度（LA、ASVspoof 2017、RIRplay 的动机）。
- 正类干净、负类有噪，或反过来（ReplayDF 对旧数据集的分析）。
- 只在 16 kHz 上训练、测试出现 48 kHz 的高频，或相反。PA 基线把带宽限制在 8 kHz，LA/DF 限制在 4 kHz，换带宽等于换特征。

## 7. 按产品场景怎么做

### 只判断「文件是不是 TTS」

用 wav2vec / AASIST 这一支，训练数据要包含目标麦克风和压缩，而不是只有 ASVspoof 2019 LA。EchoFake 和 ASVspoof 2021 DF 都说明，演播室上的低 EER 不能带到手机录音和媒体压缩。评测时按 TTS 系统、编解码、麦克风拆开，不要只报一个总 EER。

### 只判断「这段已经采集的声音是不是喇叭放的」

不要用深伪检测器。可用的做法：

1. **配对采集或配对仿真。** 同一房间、同一噪声、同一麦克风，只换声源。本仓库的 `render` 就是这个协议；`judge` 用同场景胜率而不是绝对分数，是因为绝对分数被混响和干文件带偏。
2. **特征落在声源和播放链上。** 频带边缘、随音量变化的失真、节目编解码和配乐。高品质全频设备要降低对「频谱斜率」的依赖，改用失真和节目链。
3. **把麦克风档次做成共享或显式条件。** 训练里出现差麦、好麦、远距离。差麦是正类的一部分，不是攻击。
4. **阳性对照用真二次重放，但不要优化到它上面。** 二次重放应该比单次外放更好分。若一个模型只在二次重放上好、在单次外放上回到随机，它学的是 ASVspoof 的第二遍。
5. **车舱单独留真实录音。** 仿真和 ASVspoof 都覆盖差。ReMASC 是公开数据里少数含车内真人和重放的集合，RIRplay 在上面仍有约 34% EER。

现成模型只能当弱参照：2021 PA 上最好的公开结果仍在 22–28% EER，而且正类是高品质喇叭播放的 VCTK，不是嘴。

### 三类一起要

做成 EchoFake 那样的四格更清楚，因为「外放的 TTS」和「外放的真人节目」不是同一类：

| | 没过喇叭 | 过喇叭再录 |
| --- | --- | --- |
| 真人内容 | 麦克风收录的真人 | 电视/电台里的人声 |
| TTS 内容 | TTS 文件 | 智能音箱、短视频外放的合成语音 |

开集上最难的一格是「重放的真人」：没有合成痕迹，又和真人共享房间。最容易的一格是干 TTS。若产品只需要拒掉外放、放行真人，应把两格外放合成一个拒绝类，并在训练里让拒绝类包含真人节目和 TTS 节目，否则模型会用「像不像合成」去拒，电视新闻会漏掉，干 TTS 文件反而会被拒掉。

## 8. 和本仓库仿真的对应关系

`replay_opus` 把上述文献里反复出现的混淆项从标签里拿掉了：

- 真人和外放共享房间、噪声、麦克风和采集链，标签只来自声源。这直接回应 Liu、RIRplay、ReplayDF 的结论：混响和加性噪声分不开这两类。
- 编解码放在扬声器之前的节目链上，而不是麦克风之后。麦克风之后的压缩两类都会遇到；播出编码才是电视和电话特有的。
- 外放按设备给高通、谐振、多单元和随音量变化的非线性，对应 Void 观察到的廉价喇叭功率形状，以及 Hammerstein 模型描述的扬声器非线性。
- 车舱单独成环境。公开重放语料几乎没有可用的车内监督，这里只能先靠仿真，再用真实车内录音验收。

仿真没有覆盖、文献也认为会伤泛化的部分：非矩形房间和家具（RIRplay 的局限）、麦克风阵列上的空间线索、系统自身播放的回声、以及真人嗓音（现在的声源池只有 TTS）。最后一项和 ReplayDF 的结论连在一起：模型如果只听过 TTS 的嘴，它可能在学「合成器经过房间」，而不是「声带经过房间」。有真人语料时，应放进同一个池子，两类都用。
